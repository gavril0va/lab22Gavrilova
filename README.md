Dictionary и HashSet в C#.

## Что реализовано
- хранение исключений в HashSet;

- подготовка и разделение текста на слова;

- вывод общей статистики;
- безопасный поиск слова через TryGetValue;
- все 3 самостоятельных задания.

## Короткие ответы
1. Что должно быть уникальным в Dictionary и в HashSet?
 в Dictionary уникальными должны быть ключи (key), а в HashSet уникальны элементы.

2. Чем отличается повторное добавление в HashSet от Dictionary.Add() с существующим ключом?
 HashSet.Add() при повторе просто вернет false, а Dictionary.Add() с существующим ключом вызовет ошибку, потому что ключи должны быть уникальны.

3. Почему для поиска по неизвестному ключу удобно использовать TryGetValue()?
потому что если искать через dict[key] и ключа не будет, программа упадет с ошибкой. TryGetValue() возвращает тру/фолз.
